# Metrics Definition
- **OR2A (Order to Arrive)**: Total time from order creation to delivery completion.
- **SLA Breach**: Occurs when OR2A exceeds the guaranteed delivery time for the order.
- **Breached Rate**: The ratio of breached orders to total orders in a given timeframe/location.
- **Problem Hour**: An hour flag indicating significant SLA breaches and operational challenges.
- **Pileup Count**: The number of unassigned orders waiting for a rider.
