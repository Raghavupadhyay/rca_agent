# RCA Playbook
1. **High Pileup**: If pileup_count is high, check for rider shortage. Recommend assigning more riders or reducing booking capacity.
2. **High OR2A but Low Pileup**: Check for preparation delays at the store. The store might be understaffed or processing orders slowly.
3. **High Cancellation**: Check if RTO (Return to Origin) or noshow counts are high.
4. **General SLA Breach**: Cross-reference with current_capacity_booked to see if the store was over-capacity.
